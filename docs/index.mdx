# Laakhay Data

`laakhay-data` is an async-first market data library for unified REST and streaming access across multiple exchanges.

## Start Here

If you're new, follow this order:

1. `getting-started/installation`
2. `getting-started/quickstart`
3. `getting-started/first-stream`
4. `guides/*` for production patterns
5. `examples/*` for copy/paste workflows

## Core User Value

- Single facade: `DataAPI`.
- Unified immutable models (`OHLCV`, `Trade`, `OrderBook`, `FundingRate`, ...).
- Capability-aware routing and request validation.
- High-level streaming feeds and relay pipelines.

## Typical Usage Flow

- Fetch historical data over REST.
- Start live stream(s).
- Route events through relay/sinks.
- Feed normalized data into `laakhay-ta` and `laakhay-quantlab`.

## Supported Exchanges

- Binance
- Bybit
- OKX
- Kraken
- Hyperliquid
- Coinbase

`MEXC` currently exists in connectors but is not part of default `register_all()`.
