# Overview

`laakhay-data` is a provider-agnostic crypto market data library.

## Core Focus

- Exchange-agnostic data access
- Async-first request/stream execution
- Strongly typed Pydantic data models
- Predictable interfaces across market types

## Main Building Blocks

- `DataAPI` facade for high-level usage
- Routing + capability validation layer
- Provider registry and exchange-specific connectors
- URM symbol normalization system
- Streaming feeds and sink/relay utilities

## Typical Flow

1. User calls `DataAPI.fetch_*` or `DataAPI.stream_*`
2. Request is validated against capabilities
3. Symbol is normalized/resolved through URM
4. Matching provider/transport is selected
5. Typed data models are returned/yielded
