# Getting Started

This section takes you from install to your first streaming loop.

## Prerequisites

- Python `3.12+`
- `pip` or `uv`

## In 3 Steps

1. Install the package.
2. Run a REST fetch (`fetch_ohlcv`).
3. Run a stream (`stream_trades`).

Continue to:

- `installation`
- `quickstart`
- `first-stream`
