# Installation

## Package

```bash
pip install laakhay-data
```

## Dev Dependencies (Repository)

From repo root (`data/`):

```bash
uv sync --dev
```

## Verify

```bash
python -c "import laakhay.data as d; print(d.__version__)"
```

## Runtime Dependencies

Defined in `pyproject.toml`:

- `pydantic>=2.0`
- `aiohttp>=3.8`
- `websockets>=10`
