# Provider Development

This page is for maintainers extending exchange support.

## 1. Implement Connector Package

Create `laakhay/data/connectors/<exchange>/` with:

- `provider.py` unified provider
- `rest/provider.py`
- `ws/provider.py`
- `urm.py`

## 2. Decorate Feature Handlers

Use `@register_feature_handler(DataFeature.X, TransportKind.Y)` on provider methods.

This drives both routing and capability discovery.

## 3. Add Registration Wiring

In `registration.py`:

- add `register_<exchange>(registry)`
- optionally add to `register_all()`

## 4. Add URM Mapper

Mapper must implement:

- `to_spec(exchange_symbol, market_type)`
- `to_exchange_symbol(spec, market_type)`

## 5. Add Tests

- unit tests for symbol normalization and adapters
- unit tests for provider methods and endpoint mapping
- integration tests for real exchange behavior (network-marked)

## 6. Validate Capability Discovery

After registration, verify capability map via:

```python
from laakhay.data.capability import get_exchange_capability
print(get_exchange_capability('<exchange>'))
```
