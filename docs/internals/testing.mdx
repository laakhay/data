# Testing Strategy

## Test Layout

- `tests/unit`: fast deterministic tests
- `tests/integration`: network-dependent provider integration tests

## Focus Areas

- model validation and computed properties
- request building and router arg mapping
- capability checks and fallback behavior
- provider registration and handler mapping
- feed lifecycle and subscription behavior
- sink/relay correctness

## Recommended CI Split

1. Unit tests on every push/PR.
2. Integration tests on schedule/manual or tagged runs with credentials/network gates.

## Practical Commands

```bash
pytest tests/unit -q
pytest tests/integration -m integration -q
```
