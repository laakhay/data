# Connectors

`laakhay-data` includes connector modules for multiple exchanges.

## Current Exchange Connectors

- Binance
- Bybit
- OKX
- Kraken
- Coinbase
- Hyperliquid
- MEXC

## Connector Responsibilities

- Implement exchange-specific REST handlers
- Implement exchange-specific WebSocket handlers
- Parse and normalize payloads into shared models
- Surface capabilities for routing/validation

## Why This Matters

Connectors keep exchange-specific complexity isolated, while `DataAPI` stays stable for application code.
