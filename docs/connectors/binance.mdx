# Binance

Exports:

- `BinanceProvider`
- `BinanceRESTConnector`
- `BinanceWSConnector`
- `BinanceURM`

Current registered market types: `spot`, `futures`.

Primary features:

- REST: health, ohlcv, order book, recent/historical trades, symbols, open interest, funding rates
- WS: ohlcv, trades, order book, liquidations, open interest, funding rates, mark price
