# API Reference

Use this section after you know the basic usage flow.

## Most Used Entry Points

- `laakhay.data.api.DataAPI`
- `laakhay.data.api.APIRequestBuilder`
- `laakhay.data.clients.*` feed classes
- `laakhay.data.runtime.relay.StreamRelay`
- `laakhay.data.models.*`

## How To Read This Section

- Start with `api/data-api` for day-to-day usage.
- Use `api/request-building` when you need explicit request objects.
- Use `api/feeds` and `api/relay-and-sinks` for streaming systems.
- Use `api/core` and `api/models` as deeper reference.
