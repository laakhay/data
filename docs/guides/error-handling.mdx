# Error Handling

## Exception Hierarchy

- `DataError`
- `CapabilityError`
- `ProviderError`
- `RateLimitError`
- `InvalidSymbolError`
- `InvalidIntervalError`
- `ValidationError`
- `SymbolResolutionError`
- `RelayError`

## Typical Pattern

```python
from laakhay.data.core import CapabilityError, ProviderError, SymbolResolutionError

try:
    await api.fetch_ohlcv('BTC/USDT', Timeframe.M1, exchange='binance', market_type=MarketType.SPOT)
except CapabilityError as e:
    # unsupported feature/transport on exchange
    print(e)
except SymbolResolutionError as e:
    # invalid symbol format or conversion failure
    print(e.exchange, e.value)
except ProviderError as e:
    # upstream error (HTTP, parse, etc.)
    print(e, e.status_code)
```

## Robustness Recommendations

- Validate capabilities up-front for dynamic workflows.
- Retry `ProviderError` selectively; honor `RateLimitError.retry_after`.
- Separate permanent failures (capability/symbol) from transient failures (network/upstream).
