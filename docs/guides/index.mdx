# Guides

These guides describe practical patterns and caveats for production use.

- `symbol-format-and-urm`: accepted symbol format and URM utilities.
- `capability-driven-routing`: prevent unsupported requests.
- `multi-symbol-streams`: efficient fan-in patterns.
- `chunking-and-pagination`: long-range fetches safely.
- `stream-relay-and-sinks`: feed-to-sink forwarding.
- `error-handling`: robust retry and fallback behavior.
